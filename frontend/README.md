# notes svelte fast api

a simple notes app without login

Generated by the Quorq AI SDLC platform from an approved app design.

Every screen here was generated from a design the team reviewed and approved.
A backend was also generated for this project (see `../backend/`), but these
screens still run on **seeded sample data** -- wiring a given screen to a real
endpoint is the next job, not something this repository pretends to have done.

## Approved technology stack

- **Frontend**: Svelte 5
- **Backend**: FastAPI 0.115
- **Database**: PostgreSQL 16
- **Cloud**: AWS

## Running it

```bash
npm install
npm run dev
```

`npm run build` bundles the app; it does not typecheck. The generated screens are plain
JavaScript Svelte components, and `npm run typecheck` runs `svelte-check` over the
TypeScript around them when you want it.

## Checks and tests

- `npm run lint` / `npm run lint:fix` -- ESLint over the whole app; `lint:fix` applies the
  fixes it can. The platform runs `npm run lint` as a gate during development, so keep it green.
- `npm run test` -- Vitest component tests with Testing Library for Svelte, beside the
  components they cover.
- `npm run test:e2e` -- Playwright acceptance tests from the `e2e/` folder beside `src/`.
  `npm run test:e2e:install` fetches the browser first. With `E2E_BASE_URL` set it runs against
  that deployed URL; without it, Playwright builds and serves this app and runs against that.

## Layout

- `src/screens/` -- one Svelte component per approved screen.
- `src/App.svelte` -- the navigation shell and the route table; `src/lib/router.svelte.ts`
  moves between them.
- `src/lib/ui/` -- the component and icon vocabulary the screens were written against.
- `src/lib/brand.ts`, `src/index.css` -- the approved brand, as tokens and as
  CSS variables.
